# creator_of_lecals
Создатель выкроек и 3Д-моделей

- [План прототипа](docs/prototype-plan.md)
- [Итоги M0: проверка технологий](docs/m0-results.md)
- Прототип: https://platonoriginal.github.io/creator_of_lecals/ (обновляется после каждого мержа в main)

## Конструкции и режимы

- **Женский и мужской режимы:** переключение в интерфейсе (`Женский / Мужской`), подбор и градация мужских мерок по ГОСТ 17521-72 и таблице 8 ЕМКО СЭВ.
- **Мужские конструкции (`MALE_BLOCKS`):** классические брюки (ЕМКО СЭВ и М. Мюллер и сын), сорочка ЕМКО СЭВ, пиджак и летняя куртка ЕМКО СЭВ с двухшовным рукавом.
- **Припуски, примерка и экспорт:** стачные и отделочные припуски, надсечки, 3D-манекен, библиотека моделей, журнал примерок и экспорт в PDF (A4/A0) и SVG.

## Запуск

Нужны Node.js 22+ и pnpm 10.

```bash
pnpm install
pnpm dev      # прототип в браузере, адрес покажет консоль
pnpm check    # линтер, типы, тесты
pnpm build    # сборка в apps/web/dist
```
