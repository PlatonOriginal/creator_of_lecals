## Запуск

Нужны Node.js 22+ и pnpm 10.

```bash
pnpm install
pnpm dev      # прототип в браузере, адрес покажет консоль
pnpm check    # линтер, типы, тесты
pnpm build    # сборка в apps/web/dist
```
